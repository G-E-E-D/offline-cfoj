4A / Div. 2 A — Watermelon

We need to check whether an integer $$$w$$$ ($$$1 \le w \le 100$$$) can be represented as the sum of two positive even integers $$$a + b = w$$$.

Since the sum of two even numbers is always even, any odd $$$w$$$ immediately yields NO. Furthermore, the smallest sum of two positive even integers is $$$2 + 2 = 4$$$, so $$$w = 2$$$ can only be split into $$$1 + 1$$$ (both odd) and must also output NO. For every even $$$w \ge 4$$$, we can choose $$$a = 2$$$ and $$$b = w - 2$$$, which are both positive even integers.

Time complexity: $$$O(1)$$$. Space complexity: $$$O(1)$$$.

#include <bits/stdc++.h>
int main() {
    int w;
    std::cin >> w;
    std::println("{}", (w % 2 == 0 && w > 2) ? "YES" : "NO");
}

4B / Div. 2 B — Before an Exam

Let $$$L = \sum_{i=1}^{d} minTime_i$$$ and $$$R = \sum_{i=1}^{d} maxTime_i$$$. Clearly, a valid schedule exists if and only if $$$L \le sumTime \le R$$$. If $$$sumTime < L$$$ or $$$sumTime > R$$$, output NO.

Otherwise, start by assigning $$$s_i = minTime_i$$$ for each day $$$i$$$, leaving $$$rem = sumTime - L$$$ hours to distribute. Iterate through $$$i = 1 \dots d$$$ and add $$$\delta_i = \min(rem, maxTime_i - minTime_i)$$$ to $$$s_i$$$, decreasing $$$rem$$$ by $$$\delta_i$$$. Because $$$sumTime \le R$$$, $$$rem$$$ reaches $$$0$$$ by the end of the loop.

Time complexity: $$$O(d)$$$. Space complexity: $$$O(d)$$$.

4C / Div. 2 C — Registration System

Maintain a hash map (or balanced binary search tree) std::unordered_map<std::string, int> cnt mapping each requested base username to the number of times it has been requested so far.

When username $$$s$$$ arrives: if cnt[s] == 0, output OK and increment cnt[s] to $$$1$$$. Otherwise, let $$$k = cnt[s]$$$, output $$$s + \text{to\_string}(k)$$$, and increment cnt[s]. Since the problem guarantees that input requests consist only of lowercase Latin letters (no digits), generated names containing digits can never collide with future raw input names.

Time complexity: $$$O(n \cdot |s|)$$$ expected. Space complexity: $$$O(n \cdot |s|)$$$.
